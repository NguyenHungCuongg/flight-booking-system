# Plan 19 — Báo cáo: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây dựng module backend `report` cung cấp 3 API thống kê phục vụ màn hình quản trị Admin A-10 (`/admin/reports`): Báo cáo Dòng tiền (FR-120, BR-110), Báo cáo Doanh số vé (FR-121, BR-111), và Báo cáo Tỉ lệ lấp đầy (FR-122, BR-112). Dữ liệu được tính toán chính xác bằng các câu truy vấn SQL hiệu năng cao qua `JdbcClient` theo múi giờ Việt Nam (`Asia/Ho_Chi_Minh`).

**Architecture:** Thêm module Spring Modulith `report` (chỉ phụ thuộc `common`). Module này hoạt động hoàn toàn ở chế độ chỉ đọc (read-only), không có entity JPA và không thay đổi schema DB. `ReportService` sử dụng `JdbcClient` thực thi các truy vấn Q-10, Q-11, Q-12 trực tiếp trên các bảng `payments`, `tickets`, `booking_segments`, `flights`, `flight_cabins`, `airlines`. `AdminReportController` đặt dưới `/api/admin/reports` (được bảo vệ bởi `ROLE_ADMIN` qua `SecurityConfig`), nhận khoảng ngày `[from, to]` theo `LocalDate` và chuyển đổi sang khoảng thời gian nửa đóng nửa mở `[from 00:00, to + 1 ngày 00:00)` theo múi giờ `Asia/Ho_Chi_Minh` (`+07:00`).

**Tech Stack:** Java 21, Spring Boot 4.1.1 (Spring Web MVC, `JdbcClient`, Bean Validation), Spring Modulith 2.1.1, PostgreSQL 18, Testcontainers, MockMvc, JUnit 5 + AssertJ, TypeScript (openapi-typescript 7.13.0).

**Spec:** [PRD](../../PRD.md) FR-120–122, BR-110–112 · [TDD](../../TDD.md) §3.2 (`report`), §5.1 (múi giờ báo cáo), §6.11, §8.7, §9 (`VALIDATION_FAILED`), §10 AD-05 · [App Flow](../../APP_FLOW.md) A-10 · [Backend Schema](../../BACKEND_SCHEMA.md) §6 Q-10, Q-11, Q-12, §8.4 · [Lộ trình](2026-10-09-00-roadmap.md) §1 M4, §2 dòng 19, §3, §6 dòng 19.

- **Múi giờ báo cáo (TDD §5.1, §6.11):** Báo cáo luôn tính và nhóm theo múi giờ Việt Nam `Asia/Ho_Chi_Minh` (`+07:00`). Tham số truy vấn `from` và `to` là `LocalDate`. Khoảng thời gian tra cứu DB là `[from 00:00:00+07:00, (to + 1 ngày) 00:00:00+07:00)`.
- **Quy tắc Dòng tiền (BR-110, Q-10):**
  - Chỉ tính các giao dịch `payments` có `status = 'SUCCESS'`.
  - Tổng thu (`charged`): tổng `amount` của các lượt `kind = 'CHARGE'`.
  - Tổng hoàn (`refunded`): tổng `amount` của các lượt `kind = 'REFUND'` (bao gồm cả hoàn tự động qua cổng lẫn hoàn thủ công `MANUAL`).
  - Doanh thu ròng (`net`): `totalCharged - totalRefunded`.
  - Hỗ trợ nhóm (`groupBy`): `DAY` (ngày), `MONTH` (tháng), `YEAR` (năm).
- **Quy tắc Doanh số vé (BR-111, Q-11):**
  - Chỉ tính các vé trong bảng `tickets` có `issued_at` nằm trong kỳ và thuộc chặng bay đang có trạng thái `s.status = 'ACTIVE'` (chặng đã bị hoàn `CANCELLED` hoặc đổi chuyến `REPLACED` không được tính).
  - Doanh số gồm: số lượng vé (`ticketCount`) và tổng giá vé (`revenue` = `SUM(t.fare_amount)`).
  - Hỗ trợ nhóm (`groupBy`): `AIRLINE` (theo hãng khai thác: mã và tên hãng) hoặc `ROUTE` (theo tuyến bay: `SânBayĐi-SânBayĐến`, ví dụ `HAN-SGN`). Kết quả sắp xếp theo doanh thu giảm dần.
- **Quy tắc Tỉ lệ lấp đầy (BR-112, Q-12):**
  - Tính cho các chuyến bay `flights` có `status = 'SCHEDULED'` cất cánh (`departure_time`) trong kỳ.
  - Tỉ lệ lấp đầy của chuyến = `(tổng ghế - ghế còn) / tổng ghế * 100%`, làm tròn 1 chữ số thập phân.
  - Ghế đang giữ chỗ cũng được tính là đã lấp (vì `available_seats` đã bị trừ khi giữ chỗ).
  - Hỗ trợ lọc theo hãng qua tham số tuỳ chọn `airline`. Nếu không truyền hoặc để trống, tính cho tất cả các hãng.
- **Xử lý ngoại lệ & Validation:**
  - `to` trước `from`: trả 400 `VALIDATION_FAILED` với trường `to` ("Ngày kết thúc không được trước ngày bắt đầu").
  - Tham số `groupBy` không hợp lệ: trả 400 `VALIDATION_FAILED`.
  - Quyền truy cập: Chỉ tài khoản có `ROLE_ADMIN` mới được truy cập `/api/admin/reports/**`. Khách vãng lai nhận 401 `UNAUTHENTICATED`, người dùng có vai trò `STAFF` hoặc `CUSTOMER` nhận 403 `FORBIDDEN`.
- **Test:** Integration test sử dụng `@IntegrationTest`, `@Transactional`, chạy trên PostgreSQL 18 container. Test tự tạo dữ liệu độc lập (chuyến bay, kho ghế, booking, vé, giao dịch thanh toán) qua JDBC helper, không dựa vào seed `V100`–`V106`.

## Review Focus

1. **Chuyển đổi múi giờ `Asia/Ho_Chi_Minh` và biên ngày (TDD §6.11):** Khoảng ngày `from` và `to` phải chuyển thành `[from 00:00:00+07:00, (to + 1 ngày) 00:00:00+07:00)`. Giao dịch lúc 23:59:59 của ngày `to` phải được tính, còn 00:00:00 của ngày hôm sau không được tính (Task 1 `ReportPeriodTest`, Task 2 `ReportServiceTest`).
2. **Q-10 date_trunc trong PostgreSQL JDBC:** Cần ép kiểu `date_trunc(cast(:unit as text), completed_at AT TIME ZONE 'Asia/Ho_Chi_Minh')::date` để tránh lỗi JDBC prepared statement không xác định được kiểu dữ liệu của tham số `:unit`.
3. **Q-11 Vé chặng ACTIVE:** Chỉ tính vé có `segment.status = 'ACTIVE'`. Vé thuộc chặng bị hủy (`CANCELLED`) do hoàn vé hoặc bị thay thế (`REPLACED`) do đổi chuyến không được tính vào doanh số (Task 2 `salesOnlyCountsActiveSegments`).
4. **Q-12 Phép chia tránh chia cho 0 và làm tròn:** Với chuyến bay không có ghế hoặc chưa cấu hình cabin, tỉ lệ lấp đầy phải trả về `0.0` thay vì văng lỗi chia cho 0 (`NULLIF(SUM(c.total_seats), 0)`) (Task 2 `loadFactorHandlesZeroSeatsSafely`).
5. **Bảo mật và Phân quyền:** Truy cập từ người dùng chưa đăng nhập phải bị chặn 401 `UNAUTHENTICATED`, người dùng có quyền `STAFF` hoặc `CUSTOMER` phải bị chặn 403 `FORBIDDEN`, chỉ `ADMIN` mới được phép truy vấn (Task 3 `enforcesRoleAdmin`).

package vn.edu.uit.flightbooking.report.domain;

import java.time.Instant;
import java.time.LocalDate;
import java.time.ZoneId;

import vn.edu.uit.flightbooking.common.BusinessException;

public record ReportPeriod(Instant from, Instant to) {

	public static final ZoneId VIETNAM = ZoneId.of("Asia/Ho_Chi_Minh");

	public static ReportPeriod of(LocalDate fromDate, LocalDate toDate) {
		if (fromDate == null) {
			throw BusinessException.invalidField("from", "Ngày bắt đầu không được để trống");
		}
		if (toDate == null) {
			throw BusinessException.invalidField("to", "Ngày kết thúc không được để trống");
		}
		if (toDate.isBefore(fromDate)) {
			throw BusinessException.invalidField("to", "Ngày kết thúc không được trước ngày bắt đầu");
		}
		Instant start = fromDate.atStartOfDay(VIETNAM).toInstant();
		Instant end = toDate.plusDays(1).atStartOfDay(VIETNAM).toInstant();
		return new ReportPeriod(start, end);
	}

}

package vn.edu.uit.flightbooking.report;

import java.time.Instant;
import java.util.UUID;

import org.springframework.jdbc.core.simple.JdbcClient;

/**
 * Chèn dữ liệu trực tiếp bằng SQL để test báo cáo nhanh chóng, độc lập.
 */
public final class TestReports {

	private TestReports() {
	}

	public static void insertPayment(JdbcClient jdbc, String kind, String status, long amount, Instant completedAt) {
		jdbc.sql("""
				INSERT INTO payments (txn_ref, booking_id, kind, provider, status, amount, completed_at, created_at)
				VALUES (?, NULL, ?, 'VNPAY', ?, ?, ?, ?)
				""")
			.params(UUID.randomUUID().toString().replace("-", ""), kind, status, amount, completedAt, completedAt)
			.update();
	}

	public static void insertAirline(JdbcClient jdbc, String code, String name) {
		jdbc.sql("""
				INSERT INTO airlines (code, name, ticket_prefix, active)
				VALUES (?, ?, '999', TRUE)
				ON CONFLICT (code) DO NOTHING
				""")
			.params(code, name)
			.update();
	}

	public static void insertAirport(JdbcClient jdbc, String code, String name, String city) {
		jdbc.sql("""
				INSERT INTO airports (code, name, city, country_code, timezone, active)
				VALUES (?, ?, ?, 'VN', 'Asia/Ho_Chi_Minh', TRUE)
				ON CONFLICT (code) DO NOTHING
				""")
			.params(code, name, city)
			.update();
	}

	public static long insertFlight(JdbcClient jdbc, String flightNumber, String airlineCode,
			String departureAirport, String arrivalAirport, Instant departureTime, String status) {
		return jdbc.sql("""
				INSERT INTO flights (flight_number, airline_code, departure_airport, arrival_airport,
				                     departure_time, arrival_time, aircraft_model, status)
				VALUES (?, ?, ?, ?, ?, ?, 'A321', ?)
				RETURNING id
				""")
			.params(flightNumber, airlineCode, departureAirport, arrivalAirport, departureTime,
					departureTime.plusSeconds(7200), status)
			.query(Long.class)
			.single();

package vn.edu.uit.flightbooking.report.domain;

import java.sql.ResultSet;
import java.sql.SQLException;
import java.time.LocalDate;
import java.time.OffsetDateTime;
import java.util.List;

import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
@Transactional(readOnly = true)
public class ReportService {

	private final JdbcClient jdbc;

	public ReportService(JdbcClient jdbc) {
		this.jdbc = jdbc;
	}

	public CashFlowReport getCashFlow(LocalDate from, LocalDate to, CashFlowGroupBy groupBy) {
		ReportPeriod period = ReportPeriod.of(from, to);
		String sql = """
				SELECT date_trunc(cast(:unit as text), completed_at AT TIME ZONE 'Asia/Ho_Chi_Minh')::date AS period,
				       COALESCE(SUM(amount) FILTER (WHERE kind = 'CHARGE'), 0)                             AS charged,
				       COALESCE(SUM(amount) FILTER (WHERE kind = 'REFUND'), 0)                             AS refunded,
				       COALESCE(SUM(CASE WHEN kind = 'CHARGE' THEN amount ELSE -amount END), 0)          AS net
				FROM payments
				WHERE status = 'SUCCESS'
				  AND completed_at >= :from AND completed_at < :to
				GROUP BY period
				ORDER BY period ASC
				""";
		List<CashFlowItem> items = jdbc.sql(sql)
			.param("unit", groupBy.unit())
			.param("from", period.from())
			.param("to", period.to())
			.query(ReportService::mapCashFlow)
			.list();
		return CashFlowReport.of(items);
	}

	public SalesReport getSales(LocalDate from, LocalDate to, SalesGroupBy groupBy) {
		ReportPeriod period = ReportPeriod.of(from, to);
		String sql = switch (groupBy) {
			case AIRLINE -> """
					SELECT f.airline_code AS group_key,
					       a.name         AS group_name,
					       COUNT(*)       AS tickets,
					       COALESCE(SUM(t.fare_amount), 0) AS revenue
					FROM tickets t
					JOIN booking_segments s ON s.id = t.segment_id AND s.status = 'ACTIVE'
					JOIN flights f          ON f.id = s.flight_id
					JOIN airlines a         ON a.code = f.airline_code
					WHERE t.issued_at >= :from AND t.issued_at < :to
					GROUP BY f.airline_code, a.name
					ORDER BY revenue DESC, tickets DESC
					""";
			case ROUTE -> """
					SELECT f.departure_airport || '-' || f.arrival_airport AS group_key,
					       f.departure_airport || ' → ' || f.arrival_airport AS group_name,
					       COUNT(*)           AS tickets,
					       COALESCE(SUM(t.fare_amount), 0) AS revenue
					FROM tickets t
					JOIN booking_segments s ON s.id = t.segment_id AND s.status = 'ACTIVE'
					JOIN flights f          ON f.id = s.flight_id
					WHERE t.issued_at >= :from AND t.issued_at < :to
					GROUP BY f.departure_airport, f.arrival_airport
					ORDER BY revenue DESC, tickets DESC
					""";
		};
		List<SalesItem> items = jdbc.sql(sql)
			.param("from", period.from())
			.param("to", period.to())
			.query(ReportService::mapSales)
			.list();
		return SalesReport.of(items);
	}

	public LoadFactorReport getLoadFactor(LocalDate from, LocalDate to, String airline) {
		ReportPeriod period = ReportPeriod.of(from, to);
		String normalizedAirline = (airline != null && !airline.isBlank()) ? airline.strip().toUpperCase() : null;
		String sql = """
				SELECT f.id                                           AS flight_id,
				       f.flight_number                                AS flight_number,
				       f.airline_code                                 AS airline_code,
				       f.departure_airport                            AS departure_airport,
				       f.arrival_airport                              AS arrival_airport,
				       f.departure_time                               AS departure_time,
				       COALESCE(SUM(c.total_seats), 0)                AS total_seats,
				       COALESCE(SUM(c.total_seats - c.available_seats), 0) AS occupied_seats,
				       CASE
				           WHEN COALESCE(SUM(c.total_seats), 0) = 0 THEN 0.0
				           ELSE ROUND(100.0 * SUM(c.total_seats - c.available_seats) / SUM(c.total_seats), 1)
				       END AS load_factor_percent
				FROM flights f
				LEFT JOIN flight_cabins c ON c.flight_id = f.id
				WHERE f.status = 'SCHEDULED'
				  AND f.departure_time >= :from AND f.departure_time < :to
				  AND (cast(:airline as text) IS NULL OR f.airline_code = :airline)
				GROUP BY f.id, f.flight_number, f.airline_code, f.departure_airport, f.arrival_airport, f.departure_time
				ORDER BY f.departure_time ASC, f.id ASC
				""";
		List<LoadFactorItem> items = jdbc.sql(sql)
			.param("from", period.from())
			.param("to", period.to())
			.param("airline", normalizedAirline)
			.query(ReportService::mapLoadFactor)
			.list();
		return LoadFactorReport.of(items);
	}

	private static CashFlowItem mapCashFlow(ResultSet rs, int rowNum) throws SQLException {
		LocalDate period = rs.getObject("period", LocalDate.class);
		long charged = rs.getLong("charged");
		long refunded = rs.getLong("refunded");
		long net = rs.getLong("net");
		return new CashFlowItem(period, charged, refunded, net);
	}

	private static SalesItem mapSales(ResultSet rs, int rowNum) throws SQLException {
		String groupKey = rs.getString("group_key");
		String groupName = rs.getString("group_name");
		long ticketCount = rs.getLong("tickets");
		long revenue = rs.getLong("revenue");
		return new SalesItem(groupKey, groupName, ticketCount, revenue);
	}

	private static LoadFactorItem mapLoadFactor(ResultSet rs, int rowNum) throws SQLException {
		long flightId = rs.getLong("flight_id");
		String flightNumber = rs.getString("flight_number");
		String airlineCode = rs.getString("airline_code");
		String departureAirport = rs.getString("departure_airport");
		String arrivalAirport = rs.getString("arrival_airport");
		OffsetDateTime departureTime = rs.getTimestamp("departure_time")
			.toInstant()
			.atZone(ReportPeriod.VIETNAM)
			.toOffsetDateTime();
		int totalSeats = rs.getInt("total_seats");
		int occupiedSeats = rs.getInt("occupied_seats");
		double loadFactorPercent = rs.getDouble("load_factor_percent");
		return new LoadFactorItem(flightId, flightNumber, airlineCode, departureAirport, arrivalAirport,
				departureTime, totalSeats, occupiedSeats, loadFactorPercent);
	}

}
