# Plan 06 — Quản trị chuyến bay và kho ghế: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Admin tạo chuyến lẻ hoặc cả lịch bay định kỳ, xem, sửa và xoá chuyến; Staff và Admin xem danh sách chuyến. Kho ghế giữ và trả ghế nguyên tử, không bán vượt khi nhiều luồng chạy cùng lúc. Profile `dev` có 1.200 chuyến mẫu (`V106`).

**Architecture:** Thêm module Spring Modulith `flight`, phụ thuộc `common` và `catalog`. Module này không có entity JPA: mọi câu SQL chạy bằng `JdbcClient`, vì số ghế chỉ được đổi bằng `UPDATE` có điều kiện (Q-01–Q-03) và tạo hàng loạt cần `INSERT ... ON CONFLICT DO NOTHING`. `SeatInventory` ở gói gốc `flight` là API công khai cho booking (Plan 11). `FlightService` (ghi) và `FlightQueries` (đọc) ở `flight.domain`; một controller ở `flight.web`. `catalog` có thêm `CatalogApi` để `flight` kiểm tra sân bay, hãng, gói giá. Phân quyền theo đường dẫn đã có sẵn ở `SecurityConfig` nên không phải sửa.

**Tech Stack:** Java 21, Spring Boot 4.1.1 (`JdbcClient`, Bean Validation, Spring Data `PagedModel`), Spring Modulith 2.1.1, Jackson 3, Flyway, PostgreSQL 18, Testcontainers, MockMvc. Frontend chỉ chạy lại `npm run gen:api`.

### Điểm cố ý khác TDD

1. **Module `flight` không có entity JPA** (TDD §5.4 nói tới entity có `available_seats` gắn `@Column(updatable = false)`). Không có entity thì JPA không thể ghi đè số ghế, kể cả do nhầm. Các thao tác của module đều là SQL có điều kiện (Q-01–Q-03, xoá hạng ghế chỉ khi chưa bán ghế nào, `ON CONFLICT DO NOTHING`), nên `JdbcClient` ngắn và rõ hơn entity cộng `@Modifying @Query`.
2. **Chưa tạo `FlightApi`** (lộ trình §6 dự kiến có `FlightApi` đọc chuyến). Hiện chưa module nào đọc chuyến bay. Plan 07 tạo `FlightApi` cùng phần kiểm tra và định giá hành trình. `SeatInventory` chỉ có `hold` và `release`; đổi tổng ghế (Q-03) nằm trong `FlightService` vì chỉ Admin dùng.
3. **`PUT /admin/flights/{id}` không đổi được hãng, số hiệu, sân bay đi, sân bay đến**, kể cả khi chuyến chưa có booking. BR-82 chỉ cấm khi đã có booking; TDD §8.7 cũng chỉ liệt kê "giờ, loại máy bay, hạng ghế, giá bán". Chuyến chưa có booking muốn đổi tuyến thì xoá rồi tạo lại. Bỏ được nhánh kiểm tra "đã từng có booking" và việc kiểm tra lại giá bán khi đổi hãng.

Những điểm TDD không nói, plan tự chọn:

- **`flight` đọc thẳng các bảng `airports`, `fare_families`, `booking_segments`, `booking_journeys` bằng SQL, chỉ đọc**, để lấy múi giờ, tên gói và số booking trong cùng truy vấn. `flight` không gọi được API của `booking` vì `booking` phụ thuộc `flight` (sẽ thành vòng). Cách này giống `SettingsApi` đọc bảng `users` và module `report`. Ghi thì vẫn chỉ ghi bảng của mình; kiểm tra dữ liệu đầu vào đi qua `CatalogApi`.
- **`FlightTimeChanged(flightId)` được phát ngay ở plan này**, khi giờ cất cánh hoặc hạ cánh thật sự đổi. Plan 16 chỉ cần thêm listener gửi email (BR-83).
- **Chi tiết chuyến trả JSON lồng:** `{flight: {...}, fares: [...], bookingCount}`. `flight` có cùng dạng với một phần tử của danh sách.
- **`bookingCount`** là số booking từng có chặng trên chuyến, ở mọi trạng thái (kể cả `EXPIRED`), khớp với điều kiện "đã từng có booking" của BR-82. A-06 hiện nút "Xoá" khi số này bằng 0.
- **Xoá chuyến đã từng có booking** bị chặn bởi khoá ngoại `booking_segments.flight_id` (không `CASCADE`), trả 409 `FLIGHT_HAS_BOOKINGS`. Giống cách Plan 05 phát hiện dữ liệu đã được tham chiếu.
- **Bỏ một hạng ghế** chỉ được khi chưa có ghế nào bán ra hoặc đang giữ (`available_seats = total_seats`), nếu không trả 409 `SEAT_COUNT_BELOW_SOLD`. Bỏ hạng ghế giống giảm tổng ghế về 0.
- **Giá bán được thay toàn bộ** mỗi lần sửa. Booking đã lưu bản sao giá (BR-24, BR-86) nên không bị ảnh hưởng.
- **Gói giá đã ngừng bán vẫn gắn được vào chuyến.** Tìm kiếm (Plan 07) tự loại gói ngừng bán theo BR-05; chặn ở đây sẽ làm Admin không sửa được chuyến đang có gói vừa bị ngừng.
- **Không tạo hay sửa chuyến cất cánh trong quá khứ:** trả 400 cho `fromDate` (tạo) hoặc `departureTime` (sửa). Chuyến đã cất cánh thì không sửa được (BR-87, 409 `DEADLINE_PASSED`); chuyến đã huỷ cũng không sửa được (409 `INVALID_STATE`).
- **Đổi giờ trùng với một chuyến khác cùng số hiệu** trả 400 cho `departureTime`, không phải 500.
- **`aircraftModel` bắt buộc** (FR-90 liệt kê loại máy bay là trường nhập), dù cột trong DB cho phép `NULL`. Nhờ vậy kiểu TypeScript sinh ra (`string`) đúng với dữ liệu tạo qua API.
- **Giới hạn đầu vào:** `durationMinutes` từ 1 đến 1440, `totalSeats` từ 1 đến 999, `daysOfWeek` là tên thứ tiếng Anh (`MONDAY`…`SUNDAY`, enum `DayOfWeek` của Java).
- **Danh sách chuyến** lọc theo `date` là ngày cất cánh theo giờ sân bay đi, sắp theo giờ cất cánh, mặc định 20 dòng mỗi trang.
- **Seed `V106`** lấy "ngày chạy migration" theo giờ Việt Nam, và tra hệ số giá theo tên gói (các gói trùng tên giữa các hãng có cùng hệ số ở BACKEND_SCHEMA §8.3).

### Ba bẫy khi viết test cho module này

- **Danh mục phải tạo bằng SQL, không qua API.** Test gắn `@Transactional` nên MockMvc chạy chung transaction với test. Dữ liệu tạo qua API của `catalog` (JPA) chưa flush xuống DB, nên câu `SELECT` của `flight` (JdbcClient) không thấy. `TestFlights.catalog(jdbc)` tạo sân bay, hãng, gói giá bằng SQL. Chuyến bay thì tạo qua API được, vì `flight` ghi thẳng bằng SQL.
- **Lỗi của PostgreSQL làm hỏng transaction của test.** Sau lỗi UNIQUE hoặc lỗi khoá ngoại, mọi câu SQL tiếp theo trong cùng transaction đều bị từ chối. Request gây lỗi đó phải là lệnh SQL cuối cùng của test. Lỗi nghiệp vụ (`BusinessException`) thì không sao: transaction chỉ bị đánh dấu rollback, các request sau vẫn chạy.
- **Test đồng thời không dùng được `@Transactional`.** Mỗi luồng cần transaction và connection riêng, nên `SeatInventoryTest` commit dữ liệu thật (mã `Q9`, `QZA`, `QZB` chỉ dùng ở đó) và tự dọn ở `@AfterEach`.

```java
package vn.edu.uit.flightbooking.flight;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;

import java.util.concurrent.CountDownLatch;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.TimeUnit;
import java.util.concurrent.atomic.AtomicInteger;

import org.junit.jupiter.api.AfterEach;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.jdbc.core.simple.JdbcClient;

import vn.edu.uit.flightbooking.IntegrationTest;
import vn.edu.uit.flightbooking.catalog.CabinClass;
import vn.edu.uit.flightbooking.common.BusinessException;
import vn.edu.uit.flightbooking.common.ErrorCode;

/**
 * Q-01, Q-02 và tiền đề của T1. Không dùng {@code @Transactional}: mỗi luồng cần transaction và connection riêng,
 * nên dữ liệu được commit thật và dọn ở {@link #cleanUp()}. Mã Q9, QZA, QZB chỉ dùng trong test này.
 */
@IntegrationTest
class SeatInventoryTest {

	@Autowired
	SeatInventory seats;

	@Autowired
	JdbcClient jdbc;

	long flightId;

	@BeforeEach
	void setUp() {
		jdbc.sql("INSERT INTO airlines (code, name, ticket_prefix) VALUES ('Q9', 'Hãng Ghế', '909')").update();
		jdbc.sql("""
				INSERT INTO airports (code, name, city, country_code, timezone) VALUES
				    ('QZA', 'Đi', 'Hà Nội', 'VN', 'Asia/Ho_Chi_Minh'),
				    ('QZB', 'Đến', 'Đà Nẵng', 'VN', 'Asia/Ho_Chi_Minh')
				""").update();
		flightId = jdbc.sql("""
				INSERT INTO flights (airline_code, flight_number, departure_airport, arrival_airport,
				                     departure_time, arrival_time)
				VALUES ('Q9', 'Q9100', 'QZA', 'QZB', now() + interval '2 days', now() + interval '2 days 1 hour')
				RETURNING id
				""").query(Long.class).single();
		jdbc.sql("""
				INSERT INTO flight_cabins (flight_id, cabin_class, total_seats, available_seats)
				VALUES (?, 'ECONOMY', 5, 5), (?, 'BUSINESS', 2, 2)
				""").params(flightId, flightId).update();
	}

	@AfterEach
	void cleanUp() {
		jdbc.sql("DELETE FROM flights WHERE airline_code = 'Q9'").update();
		jdbc.sql("DELETE FROM airports WHERE code IN ('QZA', 'QZB')").update();
		jdbc.sql("DELETE FROM airlines WHERE code = 'Q9'").update();
	}

	int available(CabinClass cabin) {
		return jdbc.sql("SELECT available_seats FROM flight_cabins WHERE flight_id = ? AND cabin_class = ?")
			.params(flightId, cabin.name())
			.query(Integer.class)
			.single();
	}

	/** T1 ở mức kho ghế: 20 luồng cùng giữ 1 ghế trên hạng còn 5 ghế. */
	@Test
	void twentyConcurrentHoldsNeverOversell() throws Exception {
		int threads = 20;
		ExecutorService pool = Executors.newFixedThreadPool(threads);
		CountDownLatch start = new CountDownLatch(1);
		AtomicInteger held = new AtomicInteger();
		AtomicInteger rejected = new AtomicInteger();
		for (int i = 0; i < threads; i++) {
			pool.submit(() -> {
				start.await();
				try {
					seats.hold(flightId, CabinClass.ECONOMY, 1);
					held.incrementAndGet();
				}
				catch (BusinessException e) {
					if (e.code() == ErrorCode.SEATS_UNAVAILABLE) {
						rejected.incrementAndGet();
					}
				}
				return null;
			});
		}
		start.countDown();
		pool.shutdown();
		assertThat(pool.awaitTermination(30, TimeUnit.SECONDS)).isTrue();

		assertThat(held).hasValue(5);
		assertThat(rejected).hasValue(15);
		assertThat(available(CabinClass.ECONOMY)).isZero();
	}

	@Test
```

```java
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Service;

import org.springframework.util.Assert;

import vn.edu.uit.flightbooking.catalog.CabinClass;
import vn.edu.uit.flightbooking.common.BusinessException;

/**
 * Kho ghế: giữ và trả ghế chỉ bằng {@code UPDATE} nguyên tử (Q-01, Q-02, TDD §5.4). Bên gọi chạy trong transaction
 * của mình, giữ ghế nhiều chặng theo thứ tự {@code flightId} tăng dần, và tự khoá chuyến {@code FOR SHARE} để chặn
 * huỷ chuyến chen vào (Plan 11).
 */
@Service
public class SeatInventory {

	private final JdbcClient jdbc;

	SeatInventory(JdbcClient jdbc) {
		this.jdbc = jdbc;
	}

	/** Q-01. Không đủ ghế (hoặc chuyến không có hạng này) thì báo SEATS_UNAVAILABLE. */
	@Transactional
	public void hold(long flightId, CabinClass cabin, int seats) {
		Assert.isTrue(seats > 0, "seats phải lớn hơn 0");
		int updated = jdbc.sql("""
				UPDATE flight_cabins
				SET available_seats = available_seats - :seats
				WHERE flight_id = :flightId AND cabin_class = :cabin AND available_seats >= :seats
				""")
			.param("seats", seats)
			.param("flightId", flightId)
			.param("cabin", cabin.name())
			.update();
		if (updated == 0) {
			throw new BusinessException(ErrorCode.SEATS_UNAVAILABLE, "Chuyến bay không còn đủ ghế cho hạng đã chọn");
		}
	}

	/** Q-02. Mỗi chặng rời trạng thái giữ ghế thì gọi đúng một lần (APP_FLOW §4.3). */
	@Transactional
	public void release(long flightId, CabinClass cabin, int seats) {
		Assert.isTrue(seats > 0, "seats phải lớn hơn 0");
		jdbc.sql("""
				UPDATE flight_cabins
				SET available_seats = available_seats + :seats
				WHERE flight_id = :flightId AND cabin_class = :cabin
				""")
			.param("seats", seats)
			.param("flightId", flightId)
			.param("cabin", cabin.name())
			.update();
	}

}
```

```java
import java.time.Instant;
import java.time.LocalDate;
import java.time.LocalTime;

import java.util.List;
import java.util.Map;
import java.util.Optional;
import java.util.Set;

import jakarta.validation.constraints.Max;
import jakarta.validation.constraints.Min;
import jakarta.validation.constraints.NotBlank;

/**
 * Tạo, sửa, xoá chuyến (FR-90, FR-92, FR-94; BR-80–82, BR-85–87). Dùng JdbcClient thay vì entity: số ghế chỉ được

@Service
public class FlightService {

	/** BR-85: khoảng ngày tối đa 180 ngày, tính cả ngày đầu và ngày cuối. */
	static final int MAX_DAYS = 180;

	public record CabinSeats(@NotNull CabinClass cabinClass, @NotNull @Min(1) @Max(999) Integer totalSeats) {
	}

	/** {@code price}: giá người lớn của chặng (BR-20). */
	public record FarePrice(@NotNull Long fareFamilyId, @NotNull @Min(1) Long price) {
	}

	/**
	 * Body của POST /admin/flights (FR-90). {@code departureTime} là giờ địa phương của sân bay đi. Khoảng ngày chỉ
	 * gồm một ngày nghĩa là tạo chuyến lẻ.
	 */
	public record NewFlights(@NotBlank String airlineCode, @NotBlank String flightNumber,
			@NotBlank String departureAirport, @NotBlank String arrivalAirport, @NotNull LocalTime departureTime,
			@NotNull @Min(1) @Max(1440) Integer durationMinutes, @NotNull LocalDate fromDate, @NotNull LocalDate toDate,
			@NotEmpty Set<DayOfWeek> daysOfWeek, @NotBlank @Size(max = 50) String aircraftModel,
			@NotEmpty List<@Valid CabinSeats> cabins, @NotEmpty List<@Valid FarePrice> fares) {
	}

	/** Kết quả hiện ở A-05: số chuyến tạo được và số ngày bị bỏ qua vì trùng (BR-85). */
	public record CreatedFlights(int created, int skipped, List<Long> flightIds) {
	}

	private final JdbcClient jdbc;

	private final CatalogApi catalog;

	FlightService(JdbcClient jdbc, CatalogApi catalog) {
		this.jdbc = jdbc;
		this.catalog = catalog;
	}

	/** FR-90, BR-85: mỗi ngày trong khoảng rơi vào các thứ đã chọn tạo một chuyến; ngày đã có chuyến trùng thì bỏ qua. */
	@Transactional
	public CreatedFlights create(NewFlights in) {
		if (!catalog.airlineActive(in.airlineCode())) {
			throw BusinessException.invalidField("airlineCode", "Hãng không tồn tại hoặc đã ngừng hoạt động");
		}
		if (!in.flightNumber().matches("[A-Z0-9]{2}[0-9]{1,4}") || !in.flightNumber().startsWith(in.airlineCode())) {
			throw BusinessException.invalidField("flightNumber",
					"Số hiệu gồm mã hãng và 1–4 chữ số, VD " + in.airlineCode() + "213");
		}
		ZoneId zone = activeAirportZone("departureAirport", in.departureAirport());
		activeAirportZone("arrivalAirport", in.arrivalAirport());
		if (in.departureAirport().equals(in.arrivalAirport())) {
			throw BusinessException.invalidField("arrivalAirport", "Sân bay đến phải khác sân bay đi");
		}
		if (in.toDate().isBefore(in.fromDate())) {
			throw BusinessException.invalidField("toDate", "Ngày kết thúc không được trước ngày bắt đầu");
		}
		if (ChronoUnit.DAYS.between(in.fromDate(), in.toDate()) >= MAX_DAYS) {
			throw BusinessException.invalidField("toDate", "Khoảng ngày tối đa " + MAX_DAYS + " ngày");
		}
		checkCabinsAndFares(in.airlineCode(), in.cabins(), in.fares());

		List<Long> ids = new ArrayList<>();
		int skipped = 0;
		for (LocalDate day = in.fromDate(); !day.isAfter(in.toDate()); day = day.plusDays(1)) {
			if (!in.daysOfWeek().contains(day.getDayOfWeek())) {
				continue;
			}
			Instant departure = ZonedDateTime.of(day, in.departureTime(), zone).toInstant();
			if (!departure.isAfter(Instant.now())) {
				throw BusinessException.invalidField("fromDate", "Không tạo được chuyến cất cánh trong quá khứ");
			}
			Optional<Long> id = jdbc.sql("""
					INSERT INTO flights (airline_code, flight_number, departure_airport, arrival_airport,
					                     departure_time, arrival_time, aircraft_model)
					VALUES (?, ?, ?, ?, ?, ?, ?)
					ON CONFLICT (airline_code, flight_number, departure_time) DO NOTHING
					RETURNING id
					""")
				.params(in.airlineCode(), in.flightNumber(), in.departureAirport(), in.arrivalAirport(), utc(departure),
						utc(departure.plus(in.durationMinutes(), ChronoUnit.MINUTES)), in.aircraftModel())
				.query(Long.class)
				.optional();
			if (id.isEmpty()) {
				skipped++;
				continue;
			}
			for (CabinSeats cabin : in.cabins()) {
				insertCabin(id.get(), cabin);
			}
			insertFares(id.get(), in.fares());
			ids.add(id.get());
		}
		return new CreatedFlights(ids.size(), skipped, ids);
	}

	/** BR-81: hạng ghế không lặp; mỗi giá bán thuộc một gói giá của đúng hãng, và hạng ghế của gói có trên chuyến. */
	private void checkCabinsAndFares(String airlineCode, List<CabinSeats> cabins, List<FarePrice> fares) {
		Set<CabinClass> classes = new HashSet<>();
		for (int i = 0; i < cabins.size(); i++) {
			if (!classes.add(cabins.get(i).cabinClass())) {
				throw BusinessException.invalidField("cabins[" + i + "].cabinClass", "Hạng ghế bị lặp");
			}
		}
		Map<Long, CabinClass> fareCabins = catalog.fareFamilyCabins(airlineCode);
		Set<Long> seen = new HashSet<>();
		for (int i = 0; i < fares.size(); i++) {
			String field = "fares[" + i + "].fareFamilyId";
			Long fareFamilyId = fares.get(i).fareFamilyId();
			CabinClass cabin = fareCabins.get(fareFamilyId);
			if (cabin == null) {
				throw BusinessException.invalidField(field, "Gói giá không thuộc hãng " + airlineCode);
			}
			if (!classes.contains(cabin)) {
				throw BusinessException.invalidField(field, "Chuyến không có hạng " + cabin + " của gói giá này");
			}
			if (!seen.add(fareFamilyId)) {
				throw BusinessException.invalidField(field, "Gói giá bị lặp");
			}
		}
	}

	/** BR-91: sân bay ngừng kích hoạt không chọn được cho chuyến mới. */
	private ZoneId activeAirportZone(String field, String code) {
		return catalog.airport(code)
			.filter(CatalogApi.AirportRef::active)
			.orElseThrow(() -> BusinessException.invalidField(field, "Sân bay không tồn tại hoặc đã ngừng hoạt động"))
			.zone();
	}

	private void insertCabin(long flightId, CabinSeats cabin) {
		jdbc.sql("""
				INSERT INTO flight_cabins (flight_id, cabin_class, total_seats, available_seats) VALUES (?, ?, ?, ?)
				""").params(flightId, cabin.cabinClass().name(), cabin.totalSeats(), cabin.totalSeats()).update();
	}

	private void insertFares(long flightId, List<FarePrice> fares) {
		for (FarePrice fare : fares) {
			jdbc.sql("INSERT INTO flight_fares (flight_id, fare_family_id, price) VALUES (?, ?, ?)")
				.params(flightId, fare.fareFamilyId(), fare.price())
				.update();
		}
	}

	/** PostgreSQL JDBC nhận OffsetDateTime cho cột timestamptz. */
	private static OffsetDateTime utc(Instant instant) {
		return instant.atOffset(ZoneOffset.UTC);
	}

	static BusinessException notFound() {
		return new BusinessException(ErrorCode.RESOURCE_NOT_FOUND, "Không tìm thấy chuyến bay");
	}

}
```

```java
import java.sql.ResultSet;
import java.sql.SQLException;
import java.time.OffsetDateTime;
import java.time.ZoneId;

import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import vn.edu.uit.flightbooking.catalog.CabinClass;

/**
 * Danh sách và chi tiết chuyến (FR-91). Chỉ đọc. Đọc thẳng bảng {@code airports}, {@code fare_families} (catalog) và
 * {@code booking_segments}, {@code booking_journeys} (booking) bằng SQL để lấy múi giờ, tên gói và số booking, giống
 * cách module report đọc dữ liệu.
 */
@Service
public class FlightQueries {

	public record CabinView(CabinClass cabinClass, int totalSeats, int availableSeats) {
	}

	/** Giờ theo múi giờ của sân bay tương ứng, kèm tên múi giờ IANA (TDD §5.1). Hạng ghế theo thứ tự của enum. */
	public record FlightView(long id, String airlineCode, String flightNumber, String departureAirport,
			String arrivalAirport, OffsetDateTime departureTime, String departureTimezone, OffsetDateTime arrivalTime,
			String arrivalTimezone, String aircraftModel, FlightStatus status, List<CabinView> cabins) {
	}

	public record FareView(long fareFamilyId, String fareFamilyName, CabinClass cabinClass, long price) {
	}

	/** Màn hình A-06. {@code bookingCount}: số booking từng có chặng trên chuyến, ở mọi trạng thái (BR-82). */
	public record FlightDetail(FlightView flight, List<FareView> fares, long bookingCount) {
	}

	private static final String SELECT_FLIGHT = """
			SELECT f.id, f.airline_code, f.flight_number, f.departure_airport, f.arrival_airport,
			       f.departure_time, dep.timezone AS departure_timezone,
			       f.arrival_time, arr.timezone AS arrival_timezone, f.aircraft_model, f.status
			FROM flights f
			JOIN airports dep ON dep.code = f.departure_airport
			JOIN airports arr ON arr.code = f.arrival_airport
			""";

	private final JdbcClient jdbc;

	FlightQueries(JdbcClient jdbc) {
		this.jdbc = jdbc;
	}

	@Transactional(readOnly = true)
	public FlightDetail detail(long id) {
		FlightView flight = views(SELECT_FLIGHT + " WHERE f.id = :id", Map.of("id", id)).stream()
			.findFirst()
			.orElseThrow(FlightService::notFound);
		List<FareView> fares = jdbc.sql("""
				SELECT ff.fare_family_id, fam.name, fam.cabin_class, ff.price
				FROM flight_fares ff JOIN fare_families fam ON fam.id = ff.fare_family_id
				WHERE ff.flight_id = ?
				""")
			.param(id)
			.query((rs, n) -> new FareView(rs.getLong("fare_family_id"), rs.getString("name"),
					CabinClass.valueOf(rs.getString("cabin_class")), rs.getLong("price")))
			.list()
			.stream()
			.sorted(Comparator.comparing(FareView::cabinClass).thenComparing(FareView::price))
			.toList();
		long bookingCount = jdbc.sql("""
				SELECT count(DISTINCT j.booking_id)
				FROM booking_segments s JOIN booking_journeys j ON j.id = s.journey_id
				WHERE s.flight_id = ?
				""").param(id).query(Long.class).single();
		return new FlightDetail(flight, fares, bookingCount);
	}

	/** Chạy truy vấn chuyến rồi điền hạng ghế của các chuyến đó bằng một truy vấn nữa. */
	private List<FlightView> views(String sql, Map<String, ?> params) {
		List<FlightView> flights = jdbc.sql(sql).params(params).query(FlightQueries::flight).list();
		if (flights.isEmpty()) {
			return flights;
		}
		Map<Long, FlightView> byId = flights.stream().collect(Collectors.toMap(FlightView::id, f -> f));
		jdbc.sql("SELECT flight_id, cabin_class, total_seats, available_seats FROM flight_cabins WHERE flight_id IN (:ids)")
			.param("ids", byId.keySet())
			.query(rs -> {
				byId.get(rs.getLong("flight_id"))
					.cabins()
					.add(new CabinView(CabinClass.valueOf(rs.getString("cabin_class")), rs.getInt("total_seats"),
							rs.getInt("available_seats")));
			});
		flights.forEach(f -> f.cabins().sort(Comparator.comparing(CabinView::cabinClass)));
		return flights;
	}

	private static FlightView flight(ResultSet rs, int rowNum) throws SQLException {
		String departureZone = rs.getString("departure_timezone");
		String arrivalZone = rs.getString("arrival_timezone");
		return new FlightView(rs.getLong("id"), rs.getString("airline_code"), rs.getString("flight_number"),
				rs.getString("departure_airport"), rs.getString("arrival_airport"),
				local(rs.getObject("departure_time", OffsetDateTime.class), departureZone), departureZone,
				local(rs.getObject("arrival_time", OffsetDateTime.class), arrivalZone), arrivalZone,
				rs.getString("aircraft_model"), FlightStatus.valueOf(rs.getString("status")), new ArrayList<>());
	}

	private static OffsetDateTime local(OffsetDateTime time, String zone) {
		return time.atZoneSameInstant(ZoneId.of(zone)).toOffsetDateTime();
	}

}
```

```java
package vn.edu.uit.flightbooking.flight.domain;

import java.sql.ResultSet;
import java.sql.SQLException;
import java.time.LocalDate;
import java.time.OffsetDateTime;
import java.time.ZoneId;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.stream.Collectors;

import org.springframework.data.domain.Page;
import org.springframework.data.domain.PageImpl;
import org.springframework.data.domain.Pageable;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import vn.edu.uit.flightbooking.catalog.CabinClass;

/**
 * Danh sách và chi tiết chuyến (FR-91). Chỉ đọc. Đọc thẳng bảng {@code airports}, {@code fare_families} (catalog) và
 * {@code booking_segments}, {@code booking_journeys} (booking) bằng SQL để lấy múi giờ, tên gói và số booking, giống
 * cách module report đọc dữ liệu.
 */
@Service
public class FlightQueries {

	public record CabinView(CabinClass cabinClass, int totalSeats, int availableSeats) {
	}

	/** Giờ theo múi giờ của sân bay tương ứng, kèm tên múi giờ IANA (TDD §5.1). Hạng ghế theo thứ tự của enum. */
	public record FlightView(long id, String airlineCode, String flightNumber, String departureAirport,
			String arrivalAirport, OffsetDateTime departureTime, String departureTimezone, OffsetDateTime arrivalTime,
			String arrivalTimezone, String aircraftModel, FlightStatus status, List<CabinView> cabins) {
	}

	public record FareView(long fareFamilyId, String fareFamilyName, CabinClass cabinClass, long price) {
	}

	/** Màn hình A-06. {@code bookingCount}: số booking từng có chặng trên chuyến, ở mọi trạng thái (BR-82). */
	public record FlightDetail(FlightView flight, List<FareView> fares, long bookingCount) {
	}

	private static final String SELECT_FLIGHT = """
			SELECT f.id, f.airline_code, f.flight_number, f.departure_airport, f.arrival_airport,
			       f.departure_time, dep.timezone AS departure_timezone,
			       f.arrival_time, arr.timezone AS arrival_timezone, f.aircraft_model, f.status
			FROM flights f
			JOIN airports dep ON dep.code = f.departure_airport
			JOIN airports arr ON arr.code = f.arrival_airport
			""";

	private final JdbcClient jdbc;

	FlightQueries(JdbcClient jdbc) {
		this.jdbc = jdbc;
	}

	/**
	 * Màn hình S-05, A-04. Mọi bộ lọc đều không bắt buộc; {@code date} là ngày cất cánh theo giờ sân bay đi. Sắp theo
	 * giờ cất cánh.
	 */
	@Transactional(readOnly = true)
	public Page<FlightView> list(String from, String to, LocalDate date, String airline, FlightStatus status,
			Pageable pageable) {
		StringBuilder where = new StringBuilder(" WHERE TRUE");
		Map<String, Object> params = new HashMap<>();
		if (from != null) {
			where.append(" AND f.departure_airport = :from");
			params.put("from", from);
		}
		if (to != null) {
			where.append(" AND f.arrival_airport = :to");
			params.put("to", to);
		}
		if (date != null) {
			where.append(" AND (f.departure_time AT TIME ZONE dep.timezone)::date = :date");
			params.put("date", date);
		}
		if (airline != null) {
			where.append(" AND f.airline_code = :airline");
			params.put("airline", airline);
		}
		if (status != null) {
			where.append(" AND f.status = :status");
			params.put("status", status.name());
		}
		long total = jdbc.sql("SELECT count(*) FROM flights f JOIN airports dep ON dep.code = f.departure_airport" + where)
			.params(params)
			.query(Long.class)
			.single();
		params.put("limit", pageable.getPageSize());
		params.put("offset", pageable.getOffset());
		List<FlightView> content = views(
				SELECT_FLIGHT + where + " ORDER BY f.departure_time, f.id LIMIT :limit OFFSET :offset", params);
		return new PageImpl<>(content, pageable, total);
	}

	@Transactional(readOnly = true)
	public FlightDetail detail(long id) {
		FlightView flight = views(SELECT_FLIGHT + " WHERE f.id = :id", Map.of("id", id)).stream()
			.findFirst()
			.orElseThrow(FlightService::notFound);
		List<FareView> fares = jdbc.sql("""
				SELECT ff.fare_family_id, fam.name, fam.cabin_class, ff.price
				FROM flight_fares ff JOIN fare_families fam ON fam.id = ff.fare_family_id
				WHERE ff.flight_id = ?
				""")
			.param(id)
			.query((rs, n) -> new FareView(rs.getLong("fare_family_id"), rs.getString("name"),
					CabinClass.valueOf(rs.getString("cabin_class")), rs.getLong("price")))
			.list()
			.stream()
			.sorted(Comparator.comparing(FareView::cabinClass).thenComparing(FareView::price))
			.toList();
		long bookingCount = jdbc.sql("""
				SELECT count(DISTINCT j.booking_id)
				FROM booking_segments s JOIN booking_journeys j ON j.id = s.journey_id
				WHERE s.flight_id = ?
				""").param(id).query(Long.class).single();
		return new FlightDetail(flight, fares, bookingCount);
	}

	/** Chạy truy vấn chuyến rồi điền hạng ghế của các chuyến đó bằng một truy vấn nữa. */
	private List<FlightView> views(String sql, Map<String, ?> params) {
		List<FlightView> flights = jdbc.sql(sql).params(params).query(FlightQueries::flight).list();
		if (flights.isEmpty()) {
			return flights;
		}
		Map<Long, FlightView> byId = flights.stream().collect(Collectors.toMap(FlightView::id, f -> f));
		jdbc.sql("SELECT flight_id, cabin_class, total_seats, available_seats FROM flight_cabins WHERE flight_id IN (:ids)")
			.param("ids", byId.keySet())
			.query(rs -> {
				byId.get(rs.getLong("flight_id"))
					.cabins()
					.add(new CabinView(CabinClass.valueOf(rs.getString("cabin_class")), rs.getInt("total_seats"),
							rs.getInt("available_seats")));
			});
		flights.forEach(f -> f.cabins().sort(Comparator.comparing(CabinView::cabinClass)));
		return flights;
	}

	private static FlightView flight(ResultSet rs, int rowNum) throws SQLException {
		String departureZone = rs.getString("departure_timezone");
		String arrivalZone = rs.getString("arrival_timezone");
		return new FlightView(rs.getLong("id"), rs.getString("airline_code"), rs.getString("flight_number"),
				rs.getString("departure_airport"), rs.getString("arrival_airport"),
				local(rs.getObject("departure_time", OffsetDateTime.class), departureZone), departureZone,
				local(rs.getObject("arrival_time", OffsetDateTime.class), arrivalZone), arrivalZone,
				rs.getString("aircraft_model"), FlightStatus.valueOf(rs.getString("status")), new ArrayList<>());
	}

	private static OffsetDateTime local(OffsetDateTime time, String zone) {
		return time.atZoneSameInstant(ZoneId.of(zone)).toOffsetDateTime();
	}

}
```

```java
package vn.edu.uit.flightbooking.flight.domain;

import java.time.DayOfWeek;
import java.time.Instant;
import java.time.LocalDate;
import java.time.LocalDateTime;
import java.time.LocalTime;
import java.time.OffsetDateTime;
import java.time.ZoneId;
import java.time.ZoneOffset;
import java.time.ZonedDateTime;
import java.time.temporal.ChronoUnit;
import java.util.ArrayList;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Optional;
import java.util.Set;

import jakarta.validation.Valid;
import jakarta.validation.constraints.Max;
import jakarta.validation.constraints.Min;
import jakarta.validation.constraints.NotBlank;
import jakarta.validation.constraints.NotEmpty;
import jakarta.validation.constraints.NotNull;
import jakarta.validation.constraints.Size;

import org.springframework.context.ApplicationEventPublisher;
import org.springframework.dao.DataIntegrityViolationException;
import org.springframework.dao.DuplicateKeyException;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import vn.edu.uit.flightbooking.catalog.CabinClass;
import vn.edu.uit.flightbooking.catalog.CatalogApi;
import vn.edu.uit.flightbooking.common.BusinessException;
import vn.edu.uit.flightbooking.common.ErrorCode;
import vn.edu.uit.flightbooking.flight.FlightTimeChanged;

/**
 * Tạo, sửa, xoá chuyến (FR-90, FR-92, FR-94; BR-80–82, BR-85–87). Dùng JdbcClient thay vì entity: số ghế chỉ được
 * đổi bằng UPDATE có điều kiện (TDD §5.4), và tạo hàng loạt cần {@code ON CONFLICT DO NOTHING} để bỏ qua ngày trùng.
 */
@Service
public class FlightService {

	/** BR-85: khoảng ngày tối đa 180 ngày, tính cả ngày đầu và ngày cuối. */
	static final int MAX_DAYS = 180;

	public record CabinSeats(@NotNull CabinClass cabinClass, @NotNull @Min(1) @Max(999) Integer totalSeats) {
	}

	/** {@code price}: giá người lớn của chặng (BR-20). */
	public record FarePrice(@NotNull Long fareFamilyId, @NotNull @Min(1) Long price) {
	}

	/**
	 * Body của POST /admin/flights (FR-90). {@code departureTime} là giờ địa phương của sân bay đi. Khoảng ngày chỉ
	 * gồm một ngày nghĩa là tạo chuyến lẻ.
	 */
	public record NewFlights(@NotBlank String airlineCode, @NotBlank String flightNumber,
			@NotBlank String departureAirport, @NotBlank String arrivalAirport, @NotNull LocalTime departureTime,
			@NotNull @Min(1) @Max(1440) Integer durationMinutes, @NotNull LocalDate fromDate, @NotNull LocalDate toDate,
			@NotEmpty Set<DayOfWeek> daysOfWeek, @NotBlank @Size(max = 50) String aircraftModel,
			@NotEmpty List<@Valid CabinSeats> cabins, @NotEmpty List<@Valid FarePrice> fares) {
	}

	/** Kết quả hiện ở A-05: số chuyến tạo được và số ngày bị bỏ qua vì trùng (BR-85). */
	public record CreatedFlights(int created, int skipped, List<Long> flightIds) {
	}

	/**
	 * Body của PUT /admin/flights/{id} (FR-92). Giờ là giờ địa phương của sân bay tương ứng (BR-81). Hãng, số hiệu và
	 * tuyến không đổi được.
	 */
	public record FlightChanges(@NotNull LocalDateTime departureTime, @NotNull LocalDateTime arrivalTime,
			@NotBlank @Size(max = 50) String aircraftModel, @NotEmpty List<@Valid CabinSeats> cabins,
			@NotEmpty List<@Valid FarePrice> fares) {
	}

	private record Current(String airlineCode, String departureAirport, String arrivalAirport, Instant departureTime,
			Instant arrivalTime, FlightStatus status) {
	}

	private final JdbcClient jdbc;

	private final CatalogApi catalog;

	private final ApplicationEventPublisher events;

	FlightService(JdbcClient jdbc, CatalogApi catalog, ApplicationEventPublisher events) {
		this.jdbc = jdbc;
		this.catalog = catalog;
		this.events = events;
	}

	/** FR-90, BR-85: mỗi ngày trong khoảng rơi vào các thứ đã chọn tạo một chuyến; ngày đã có chuyến trùng thì bỏ qua. */
	@Transactional
	public CreatedFlights create(NewFlights in) {
		if (!catalog.airlineActive(in.airlineCode())) {
			throw BusinessException.invalidField("airlineCode", "Hãng không tồn tại hoặc đã ngừng hoạt động");
		}
		if (!in.flightNumber().matches("[A-Z0-9]{2}[0-9]{1,4}") || !in.flightNumber().startsWith(in.airlineCode())) {
			throw BusinessException.invalidField("flightNumber",
					"Số hiệu gồm mã hãng và 1–4 chữ số, VD " + in.airlineCode() + "213");
		}
		ZoneId zone = activeAirportZone("departureAirport", in.departureAirport());
		activeAirportZone("arrivalAirport", in.arrivalAirport());
		if (in.departureAirport().equals(in.arrivalAirport())) {
			throw BusinessException.invalidField("arrivalAirport", "Sân bay đến phải khác sân bay đi");
		}
		if (in.toDate().isBefore(in.fromDate())) {
			throw BusinessException.invalidField("toDate", "Ngày kết thúc không được trước ngày bắt đầu");
		}
		if (ChronoUnit.DAYS.between(in.fromDate(), in.toDate()) >= MAX_DAYS) {
			throw BusinessException.invalidField("toDate", "Khoảng ngày tối đa " + MAX_DAYS + " ngày");
		}
		checkCabinsAndFares(in.airlineCode(), in.cabins(), in.fares());

		List<Long> ids = new ArrayList<>();
		int skipped = 0;
		for (LocalDate day = in.fromDate(); !day.isAfter(in.toDate()); day = day.plusDays(1)) {
			if (!in.daysOfWeek().contains(day.getDayOfWeek())) {
				continue;
			}
			Instant departure = ZonedDateTime.of(day, in.departureTime(), zone).toInstant();
			if (!departure.isAfter(Instant.now())) {
				throw BusinessException.invalidField("fromDate", "Không tạo được chuyến cất cánh trong quá khứ");
			}
			Optional<Long> id = jdbc.sql("""
					INSERT INTO flights (airline_code, flight_number, departure_airport, arrival_airport,
					                     departure_time, arrival_time, aircraft_model)
					VALUES (?, ?, ?, ?, ?, ?, ?)
					ON CONFLICT (airline_code, flight_number, departure_time) DO NOTHING
					RETURNING id
					""")
				.params(in.airlineCode(), in.flightNumber(), in.departureAirport(), in.arrivalAirport(), utc(departure),
						utc(departure.plus(in.durationMinutes(), ChronoUnit.MINUTES)), in.aircraftModel())
				.query(Long.class)
				.optional();
			if (id.isEmpty()) {
				skipped++;
				continue;
			}
			for (CabinSeats cabin : in.cabins()) {
				insertCabin(id.get(), cabin);
			}
			insertFares(id.get(), in.fares());
			ids.add(id.get());
		}
		return new CreatedFlights(ids.size(), skipped, ids);
	}

	/**
	 * FR-92. Khoá chuyến {@code FOR UPDATE} trước (thứ tự khoá TDD §5.4), nên không booking nào giữ ghế chen vào
	 * giữa lúc kiểm tra và lúc ghi. Đổi giờ thì phát {@link FlightTimeChanged} (BR-83).
	 */
	@Transactional
	public void update(long id, FlightChanges in) {
		Current current = jdbc.sql("""
				SELECT airline_code, departure_airport, arrival_airport, departure_time, arrival_time, status
				FROM flights WHERE id = ? FOR UPDATE
				""")
			.param(id)
			.query((rs, n) -> new Current(rs.getString("airline_code"), rs.getString("departure_airport"),
					rs.getString("arrival_airport"), rs.getObject("departure_time", OffsetDateTime.class).toInstant(),
					rs.getObject("arrival_time", OffsetDateTime.class).toInstant(),
					FlightStatus.valueOf(rs.getString("status"))))
			.optional()
			.orElseThrow(FlightService::notFound);
		if (current.status() == FlightStatus.CANCELLED) {
			throw new BusinessException(ErrorCode.INVALID_STATE, "Chuyến đã huỷ nên không sửa được");
		}
		if (!current.departureTime().isAfter(Instant.now())) {
			throw new BusinessException(ErrorCode.DEADLINE_PASSED, "Chuyến đã cất cánh nên không sửa được");
		}
		Instant departure = in.departureTime().atZone(zone(current.departureAirport())).toInstant();
		Instant arrival = in.arrivalTime().atZone(zone(current.arrivalAirport())).toInstant();
		if (!departure.isAfter(Instant.now())) {
			throw BusinessException.invalidField("departureTime", "Giờ cất cánh phải sau thời điểm hiện tại");
		}
		if (!arrival.isAfter(departure)) {
			throw BusinessException.invalidField("arrivalTime", "Giờ hạ cánh phải sau giờ cất cánh");
		}
		checkCabinsAndFares(current.airlineCode(), in.cabins(), in.fares());

		try {
			jdbc.sql("""
					UPDATE flights SET departure_time = ?, arrival_time = ?, aircraft_model = ?, updated_at = now()
					WHERE id = ?
					""").params(utc(departure), utc(arrival), in.aircraftModel(), id).update();
		}
		catch (DuplicateKeyException e) {
			throw BusinessException.invalidField("departureTime", "Đã có chuyến cùng số hiệu cất cánh đúng giờ này");
		}
		updateCabins(id, in.cabins());
		jdbc.sql("DELETE FROM flight_fares WHERE flight_id = ?").param(id).update();
		insertFares(id, in.fares());
		if (!departure.equals(current.departureTime()) || !arrival.equals(current.arrivalTime())) {
			events.publishEvent(new FlightTimeChanged(id));
		}
	}

	/** FR-94, BR-82: chuyến đã từng có booking thì khoá ngoại của booking_segments chặn xoá. */
	@Transactional
	public void delete(long id) {
		try {
			if (jdbc.sql("DELETE FROM flights WHERE id = ?").param(id).update() == 0) {
				throw notFound();
			}
		}
		catch (DataIntegrityViolationException e) {
			throw new BusinessException(ErrorCode.FLIGHT_HAS_BOOKINGS, "Chuyến đã có booking nên không xoá được");
		}
	}

	/**
	 * BR-82: đổi tổng ghế bằng Q-03, bỏ hạng ghế chỉ khi chưa có ghế nào bán ra hoặc đang giữ. Cả hai là câu lệnh có
	 * điều kiện, nên đúng cả khi có booking đang giữ ghế cùng lúc.
	 */
	private void updateCabins(long id, List<CabinSeats> cabins) {
		Map<CabinClass, Integer> current = new HashMap<>();
		jdbc.sql("SELECT cabin_class, total_seats FROM flight_cabins WHERE flight_id = ?")
			.param(id)
			.query(rs -> {
				current.put(CabinClass.valueOf(rs.getString("cabin_class")), rs.getInt("total_seats"));
			});
		for (CabinSeats cabin : cabins) {
			Integer total = current.remove(cabin.cabinClass());
			if (total == null) {
				insertCabin(id, cabin);
			}
			else if (!total.equals(cabin.totalSeats()) && jdbc.sql("""
					UPDATE flight_cabins
					SET available_seats = available_seats + (:newTotal - total_seats), total_seats = :newTotal
					WHERE flight_id = :flightId AND cabin_class = :cabin
					  AND available_seats + (:newTotal - total_seats) >= 0
					""")
				.param("newTotal", cabin.totalSeats())
				.param("flightId", id)
				.param("cabin", cabin.cabinClass().name())
				.update() == 0) {
				throw new BusinessException(ErrorCode.SEAT_COUNT_BELOW_SOLD,
						"Hạng " + cabin.cabinClass() + " đã bán hoặc đang giữ nhiều hơn " + cabin.totalSeats() + " ghế");
			}
		}
		for (CabinClass removed : current.keySet()) {
			if (jdbc.sql("""
					DELETE FROM flight_cabins
					WHERE flight_id = ? AND cabin_class = ? AND available_seats = total_seats
					""").params(id, removed.name()).update() == 0) {
				throw new BusinessException(ErrorCode.SEAT_COUNT_BELOW_SOLD,
						"Không bỏ được hạng " + removed + " vì đã có ghế bán ra hoặc đang giữ");
			}
		}
	}

	/** BR-81: hạng ghế không lặp; mỗi giá bán thuộc một gói giá của đúng hãng, và hạng ghế của gói có trên chuyến. */
	private void checkCabinsAndFares(String airlineCode, List<CabinSeats> cabins, List<FarePrice> fares) {
		Set<CabinClass> classes = new HashSet<>();
		for (int i = 0; i < cabins.size(); i++) {
			if (!classes.add(cabins.get(i).cabinClass())) {
				throw BusinessException.invalidField("cabins[" + i + "].cabinClass", "Hạng ghế bị lặp");
			}
		}
		Map<Long, CabinClass> fareCabins = catalog.fareFamilyCabins(airlineCode);
		Set<Long> seen = new HashSet<>();
		for (int i = 0; i < fares.size(); i++) {
			String field = "fares[" + i + "].fareFamilyId";
			Long fareFamilyId = fares.get(i).fareFamilyId();
			CabinClass cabin = fareCabins.get(fareFamilyId);
			if (cabin == null) {
				throw BusinessException.invalidField(field, "Gói giá không thuộc hãng " + airlineCode);
			}
			if (!classes.contains(cabin)) {
				throw BusinessException.invalidField(field, "Chuyến không có hạng " + cabin + " của gói giá này");
			}
			if (!seen.add(fareFamilyId)) {
				throw BusinessException.invalidField(field, "Gói giá bị lặp");
			}
		}
	}

	/** BR-91: sân bay ngừng kích hoạt không chọn được cho chuyến mới. */
	private ZoneId activeAirportZone(String field, String code) {
		return catalog.airport(code)
			.filter(CatalogApi.AirportRef::active)
			.orElseThrow(() -> BusinessException.invalidField(field, "Sân bay không tồn tại hoặc đã ngừng hoạt động"))
			.zone();
	}

	/** Sân bay của chuyến đã có luôn tồn tại (khoá ngoại), kể cả khi đã ngừng kích hoạt. */
	private ZoneId zone(String airportCode) {
		return catalog.airport(airportCode).orElseThrow().zone();
	}

	private void insertCabin(long flightId, CabinSeats cabin) {
		jdbc.sql("""
				INSERT INTO flight_cabins (flight_id, cabin_class, total_seats, available_seats) VALUES (?, ?, ?, ?)
				""").params(flightId, cabin.cabinClass().name(), cabin.totalSeats(), cabin.totalSeats()).update();
	}

	private void insertFares(long flightId, List<FarePrice> fares) {
		for (FarePrice fare : fares) {
			jdbc.sql("INSERT INTO flight_fares (flight_id, fare_family_id, price) VALUES (?, ?, ?)")
				.params(flightId, fare.fareFamilyId(), fare.price())
				.update();
		}
	}

	/** PostgreSQL JDBC nhận OffsetDateTime cho cột timestamptz. */
	private static OffsetDateTime utc(Instant instant) {
		return instant.atOffset(ZoneOffset.UTC);
	}

	static BusinessException notFound() {
		return new BusinessException(ErrorCode.RESOURCE_NOT_FOUND, "Không tìm thấy chuyến bay");
	}

}
```
