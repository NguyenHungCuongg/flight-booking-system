# Danh sách ảnh chụp màn hình

Agent thêm một dòng mỗi khi đặt placeholder ảnh trong một chương. Chụp xong: lưu ảnh vào `images/` đúng tên file, xóa dòng placeholder `[👉 CHÚ Ý: ...]` trong chương, bỏ comment dòng `![...]` ngay dưới, rồi đánh dấu `x` ở cột cuối.

Tài khoản demo (profile `dev`): `admin@demo.local`, `staff@demo.local`, `customer@demo.local`, mật khẩu `Demo@1234`.

| STT | File ảnh | Chương / Mục | Màn hình (route) | Tài khoản | Dữ liệu / trạng thái cần chuẩn bị | Đã chụp |
| --- | -------- | ------------ | ---------------- | --------- | --------------------------------- | ------- |
